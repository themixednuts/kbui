### [blocker] [critic] src/agents/auth-agent.ts:421
PROBLEM: reconcileFirmwareRepositories wraps every per-row repair in selfHeal (Effect.retry with an unconditional jittered Schedule.spaced — no `while` predicate, no cap), then Effect.maps the forEach to a constant `{ checked: rows.length, failed: 0, repaired: rows.length }`. FIX: Replace selfHeal with Effect.retry({ schedule: Schedule.exponential(...).pipe(Schedule.compose(Schedule.recurs(n))), while: isTransient }) using a tagged transient/permanent error split (Schema.TaggedErrorClass with a `retryable` field feeding retryTransient), and compute the summary honestly: Effect.forEach over Effect.result (or Effect.either) per row, then count Exit successes/failures into { checked, failed, repaired }.
