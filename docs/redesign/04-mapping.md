# New Design To Existing App Mapping

Sources read: handoff files under `resources/kbgui-handoff/kbgui/project/`, routes under `src/routes/(workbench)/`, reusable components under `src/lib/components/`, and keyboard domain modules under `src/lib/keyboard/`.

## Current Workbench Routes

The leaf page files are thin renderers. `src/routes/(workbench)/+layout.svelte` owns the route snippets, topbar, workbench state, keyboard editing, diff, logic, and firmware panels; `src/routes/(workbench)/+layout.ts` loads the VIA catalog index.

| Current route | File                                                                                       | Current behavior                                                                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `keymap`      | `src/routes/(workbench)/keymap/+page.svelte`                                               | Renders `pages.keymap()`. In `+layout.svelte`, this includes connect onboarding when the workbench is not ready, keymap binding mode, RGB mode, layer chips, key inspector, combo/layer markers, zoom and pan. |
| `lighting`    | `src/routes/(workbench)/lighting/+page.svelte`; `src/routes/(workbench)/lighting/+page.ts` | Renders `pages.lighting()`. The current layout snippet is an empty `<section class="view-shell"></section>`; practical RGB editing lives in the `keymap` route's RGB mode.                                     |
| `logic`       | `src/routes/(workbench)/logic/+page.svelte`                                                | Renders `pages.logic()`, which delegates to `src/lib/components/logic/LogicBuilder.svelte` for macros, combos, and tap dances.                                                                                 |
| `versioning`  | `src/routes/(workbench)/versioning/+page.svelte`                                           | Renders `pages.versioning()`: change panel, visual/source diff, commit/discard/sync, and local fork graph.                                                                                                     |
| `firmware`    | `src/routes/(workbench)/firmware/+page.svelte`                                             | Renders `pages.firmware()`: firmware output placeholder, target/readiness, generated source, behavior settings, and split transport controls.                                                                  |
