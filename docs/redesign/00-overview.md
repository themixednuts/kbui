# Redesign Overview

## Concept

Klakson is a QMK/ZMK keyboard workbench prototype for connecting a board, editing key bindings and per-key lighting on the same keyboard surface, defining reusable logic, adopting community keymaps, saving versions, and flashing firmware. The handoff is a React/JSX browser prototype loaded from `resources/kbgui-handoff/kbgui/project/Klakson.html`; it is not wired to the Svelte runtime or existing engine.

## Shell And Navigation

| Area            | Source                                               | Structure / behavior                                                                                                                                                                                                                            |
| --------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Entry document  | `resources/kbgui-handoff/kbgui/project/Klakson.html` | Loads `styles.css`, React 18, ReactDOM, Babel standalone, then `data.js`, `store.jsx`, `tweaks-panel.jsx`, `shared.jsx`, `keyboard.jsx`, `artboards-keymap.jsx`, `artboards-diff.jsx`, `artboards-rest.jsx`, `browse.jsx`, and `app-shell.jsx`. |
| App root        | `KlaksonApp` in `Klakson.html`                       | Wraps `<AppShell />` in `KStore.StoreProvider`; renders a `TweaksPanel`; writes the selected accent to `document.documentElement.style.setProperty("--coral", tweaks.accent)`.                                                                  |
| Left navigation | `AppShell` in `app-shell.jsx`                        | Fixed left rail with brand, nav items `Connect`, `Editor`, `Browse`, `Library`, `Versions`, `Settings`, account/profile footer, and device status footer.                                                                                       |
| Main chrome     | `AppShell` in `app-shell.jsx`                        | Non-connect routes show an appbar with route title, connected board chip, current variant chip, optional Monkeytype WPM chip, Save point button when dirty, and Flash/Connect primary action.                                                   |
| Context banners | `AppShell` in `app-shell.jsx`                        | Shows a placement banner when placing a macro/tap dance on a single key. Combo placement has an editor-local pick bar in `EditorView`.                                                                                                          |
| Global overlays | `AppShell`, `FlashOverlay`, `TweaksPanel`            | Toast auto-clears after 2400 ms; flash overlay renders over all routes; tweak panel is host-controlled edit-mode chrome.                                                                                                                        |
